# Skill: seo-audit

Run on every new/changed page and before launch.
- [ ] Target keyword & intent match; H1 contains it naturally
- [ ] Title 50–60 chars, description 140–160, unique
- [ ] Canonical correct; indexable; in sitemap; robots ok
- [ ] JSON-LD valid (Rich Results Test); NAP matches `site.ts`
- [ ] Internal links ≥3 in/out with descriptive anchors; breadcrumbs
- [ ] Images: alt, dimensions, next-gen; OG image 1200×630
- [ ] Headings hierarchy; readable copy; no keyword stuffing; unique content (no duplicated area pages)
- [ ] Mobile Lighthouse ≥ 95; CWV in budget
- [ ] Redirects/404 behave; no mixed content
- [ ] Search Console: URL Inspection → request indexing after publish
Report: pass/fail list + fixes applied + remaining risks.
