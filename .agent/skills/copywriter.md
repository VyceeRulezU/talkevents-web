# Skill: copywriter

Inputs: page, audience segment, keyword, proof available, tone. Follow `rules/content-guidelines.md`.
Structure: outcome-led headline → who it's for → what's included → how it works (process) → proof → FAQs → CTA.
Rules: no invented facts (placeholders), concrete over abstract, Nigerian English, ≤ 20-word sentences on average, sentence-case headings, CTA states the outcome.
Deliver: copy in the content file + meta title/description + 3 internal link suggestions + open questions.
