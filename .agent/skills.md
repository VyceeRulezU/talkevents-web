# Skills Index

Skills are repeatable recipes. Before doing a listed task, open the matching skill and follow it.

| Task | Skill file | Trigger phrases |
|---|---|---|
| Build a UI component | `skills/component-builder.md` | "add a component", "build a card/button/section" |
| Add or change a design token | `skills/generate-css-variable.md` | "new colour/size/spacing", "add token" |
| Build a full page | `skills/page-builder.md` | "add the services page", "new landing page" |
| Build a form / enquiry flow | `skills/form-builder.md` | "contact form", "book a consultation" |
| Optimise & place images | `skills/image-optimizer.md` | "add gallery", "hero image", "portfolio" |
| Audit SEO for a page | `skills/seo-audit.md` | "check SEO", "meta", "schema" |
| Write / edit copy | `skills/copywriter.md` | "write the about page", "hero copy" |

## Skill authoring format
Each skill has: **Purpose · Inputs · Steps · Output contract · Checklist · Anti-patterns**.
Keep skills short; link to rules instead of repeating them.

## When no skill fits
Follow `agent.md` §2. If you do the task more than twice, propose a new skill.
